# Continuous Fluid Flow Autonomous Driving

Source code of the autonomous driving algorithm developed by
**Tomasz Sułkowski** ([www.CodeAndDrive.com](https://www.CodeAndDrive.com))
during the PhD
thesis:

> **"Implementacja algorytmu autonomicznej jazdy w symulowanym ruchu
> ulicznym"** (*Implementation of an autonomous driving algorithm in
> simulated street traffic*)
> Politechnika Śląska (Silesian University of Technology), Gliwice, 2021.

Main publication:

> T. Sułkowski, J. Izydorczyk, M. Szelest, **"Autonomous Driving Using Fluid
> Flow Simulation"**, *IEEE Access*, vol. 10, pp. 33349–33361, 2022.
> https://doi.org/10.1109/ACCESS.2022.3161727
